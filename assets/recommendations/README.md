# 开款推荐图片

图片请分别放入以下文件夹：

- `suit/combinations/`：西装 / 西装套装－组合形式
- `suit/development/`：西装 / 西装套装－推荐开发方向
- `suit/colors/`：西装 / 西装套装－推荐颜色
- `suit/fabrics/`：西装 / 西装套装－推荐面料 / 纹样
- `suit/details/`：西装 / 西装套装－推荐细节
- `trousers/length/`：西裤 / 正装裤－推荐裤长
- `trousers/fit/`：西裤 / 正装裤－推荐裤型
- `trousers/fabrics/`：西裤 / 正装裤－推荐面料 / 纹样
- `trousers/details/`：西裤 / 正装裤－推荐细节
- `vest-tailcoat/collar/`：马甲－推荐领型
- `vest-tailcoat/button/`：马甲－推荐扣型
- `vest-tailcoat/fabric/`：马甲－推荐面料 / 纹样
- `vest-tailcoat/details/`：马甲－推荐细节
- `shirt/development/`：衬衫－推荐开发方向
- `shirt/colors/`：衬衫－推荐颜色
- `shirt/fabrics/`：衬衫－推荐面料 / 纹样
- `shirt/details/`：衬衫－推荐细节

图片放入文件夹并推送到 GitHub 后，网页会自动读取，无需登记文件名或修改代码。

分类标题、目录以及是否显示推款联系人统一在根目录的 `data/navigation.js` 中维护。

建议使用容易识别的名称，例如：

- `01-黑色商务西装.jpg`
- `02-灰色休闲西装.jpg`

网页会按照文件名顺序排列。开头的数字序号只用于控制顺序，不会显示在图片标题中；例如 `01-黑色商务西装.jpg` 在网页中显示为“黑色商务西装”。

需要添加标签时，将任意标签文字写在 `【】` 中：

- `03-双排扣西装【稀缺】.jpg`
- `04-拼接马甲【重点】.jpg`
- `05-休闲衬衫【新品】【夏季】.jpg`

网页会自动隐藏文件名中的方括号内容，并在标题旁显示“·稀缺”“·重点”“·新品”“·夏季”等标签。一个文件名可以填写多个标签；原有的 `【稀缺】` 命名继续有效。

西装 / 西装套装图片可以在名称后使用中文冒号和顿号填写关键词：

- `01-英伦乡村：粗花呢、棕、橄榄绿、灰、秋冬、复古、户外休闲.jpg`

西装 / 西装套装页面会显示标题“英伦乡村”，并在标题下方显示“粗花呢 · 棕 · 橄榄绿 · 灰 · 秋冬 · 复古 · 户外休闲”。关键词功能仅用于西装 / 西装套装，其他推荐类目的文件名不会按此规则拆分。

如果只是更新图片，保持文件名不变，直接覆盖原图片再推送即可。
